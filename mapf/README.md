# Reproducing the ICRA MAPF execution comparisons

The validated controller table is **`cache/compatible_brt.npz`**, generated by
`precompute_compatible_brt.py` (NumPy first-order local Lax–Friedrichs,
81×81×64, 0.6 s, capture distance 0.5, speeds/turn bounds 1).
`dubins_brt_81x64.npz` is a separate legacy ENO2-model cache. It is not the
controller table and the compatible loader rejects it. HJ-Reach is a related
solver; it did not generate the reported controller table.

From this `mapf/` directory, use Python with NumPy, SciPy (with `optimize.milp`),
Matplotlib, Pillow, and pytest; CMake, a C++11 compiler, and Boost headers build
CCBS. Recorded package versions and file hashes are in
`results/external_baseline_summary.json`. All distances are in grid cells.

```bash
python3 experiments/precompute_compatible_brt.py \
  --n-xy 81 --n-theta 64 --horizon 0.6 --capture-radius 0.5 \
  --speed 1 --turn-rate 1 --relative-disturbance 0.33941125496954283 \
  --out cache/compatible_brt.npz
OPENBLAS_NUM_THREADS=1 pytest -q
python3 experiments/compatible_control_demo.py --plot
OPENBLAS_NUM_THREADS=1 python3 experiments/compare_shields.py \
  --seeds 30 --n-agents 14 --total-ticks 40 \
  --policies geometric flee_matched single_constraint \
  --out results/original_baselines_rerun.json
OPENBLAS_NUM_THREADS=1 python3 experiments/compare_shields.py \
  --seeds 30 --n-agents 14 --total-ticks 40 \
  --policies chen_mip_0.15 compatible --out results/mip_comparison_30seeds.json
OPENBLAS_NUM_THREADS=1 python3 experiments/compare_shields.py \
  --seeds 30 --n-agents 14 --total-ticks 40 \
  --policies chen_mip_0.1 --out results/mip_threshold_30seeds.json
OPENBLAS_NUM_THREADS=1 python3 experiments/compare_shields.py \
  --seeds 30 --n-agents 3 --total-ticks 40 \
  --policies chen_mip_0.15 compatible --out results/mip_three_agents_30seeds.json
```

Recomputation changes the cache file hash because metadata includes solve time;
retain the supplied cache to reproduce the recorded hashes. The node values
and model parameters can instead be compared when recomputing.

## CCBS on MAPF_R

MAPF_R is the problem definition, not another execution algorithm. The CCBS
experiment uses the authors' public implementation pinned to the revision below.
It tests 30 one-task, 14-agent warehouse instances with distinct goals and a
10-second planning limit. Solved continuous-time schedules are checked
independently for swept-disc collisions and tracked with three controllers:
unfiltered bounded-turn execution, Chen MIP adaptation, and simultaneous filter.
Wait durations are kept as real numbers. Each paired rollout lasts the nominal
makespan plus 5 seconds; raw XML inputs, solution paths, logs, and timeouts are
retained. These are not 120-second lifelong episodes and must not be pooled with
the lifelong contact table. Final goal error exposes lost progress.

```bash
mkdir -p external
# Omit clone if this pinned checkout already exists.
git clone https://github.com/PathPlanning/Continuous-CBS.git external/Continuous-CBS
git -C external/Continuous-CBS checkout b8f45e166cf39ee7e8e06f0bfe4fbab0dee68932
cmake -S external/Continuous-CBS -B external/Continuous-CBS/build
cmake --build external/Continuous-CBS/build -j4
OPENBLAS_NUM_THREADS=1 python3 experiments/compare_ccbs.py \
  --source "$PWD/external/Continuous-CBS" --out "$PWD/results/ccbs_30seeds" \
  --seeds 30 --agents 14 --time-limit 10
python3 experiments/summarize_external_baselines.py
```

## Controller definitions and limitations

- **Matched flee:** same compatible table, geometric padding, margin, velocity
  disturbance and executor as the barrier arms. Each robot scans opponents in
  identifier order, chooses the first strictly higher-priority robot for which
  either directed adjusted value is nonpositive, commands unit speed away from
  it, and clips the proportional heading turn to ±1 rad/s. It is not the HJ
  gradient-optimal safety controller.
- **One constraint:** selects the lowest barrier opponent and projects the
  nominal turn onto that opponent's inequalities.
- **Simultaneous:** projects onto all monitored inequalities; reports empty
  intersections and uses least-violation fallback for these research runs.
- **Chen MIP adaptation:** reproduces Chen, Shih, and Tomlin (2016), equations
  (4)–(7), with SciPy/HiGHS binary optimization and zero relative MIP gap.
  Each robot has at most one outgoing assignment; reciprocal assignments are
  forbidden. Conflicting rewards are squared fixed priorities; other rewards
  are −1. The published N=3 priority matrix is used unchanged. For N>3 we use a
  cyclic offset ordering, recorded in `src/chen_mip.py`; this is an adaptation.
  Assigned robots maximize the selected pair's worst-case value derivative.
  K=0.15 preserves the published K/capture-distance ratio of 0.3; K=0.1 is a
  threshold sensitivity check. Repeated binary objectives reuse their solved
  assignment. The finite-horizon, disturbed warehouse model does not reproduce
  the original infinite-horizon certificate or its original v=5, capture=5
  experiment. Do not claim these results refute Chen's theorem.

The lifelong planner updates task state from committed grid cells, not physical
arrival. Continuous obstacle avoidance and certified recovery are absent.
Initial contact is excluded from onset counts; ongoing contact is not counted
again, but re-entry after separation is a new onset. Non-barrier arms' zero
constraint diagnostic fields mean unmeasured, not certified feasible. Numerical
barrier feasibility at samples is not a continuous-time safety guarantee.

The old `sweep_agents.json` and `multiseed_results.json` use historical controllers
and displacement noise. They are retained for provenance and excluded from the
new sensitivity/comparison claims.

```bash
python3 experiments/make_brt_animation.py --brt cache/compatible_brt.npz \
  --static-only --out-dir /path/to/ICRA2027/figures

bibtex icra27

```

the controller table. Black boundaries are numerical V=0 contours, not certified
inevitability sets. The reported node fraction is domain dependent.
